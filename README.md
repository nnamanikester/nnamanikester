## About

I'm a software engineer from Nigeria who builds products end to end, from the database schema to the last pixel of the mobile UI. I ship web platforms with **Next.js** and **React**, cross-platform apps with **React Native** and native **Android**, and the **Node · NestJS · GraphQL** services that power them.

- 🚚 &nbsp;Building **Pickriders**: customer, rider, inventory and admin apps, a storefront, and the backend that ties them together
- 🏢 &nbsp;Engineering at **X3Codes**
- ✍️ &nbsp;Writing and shipping at **[kescript.com](https://kescript.com)**
- 💬 &nbsp;Ask me about React Native, GraphQL, or turning a rough idea into a shipped v1
